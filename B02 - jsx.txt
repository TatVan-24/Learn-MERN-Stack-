============================================================
           TỔNG HỢP KIẾN THỨC TOÀN DIỆN VỀ JSX
============================================================

1. JSX LÀ GÌ?
- JSX (JavaScript XML) là cú pháp mở rộng cho JavaScript.
- Cho phép viết mã giống HTML ngay trong file JavaScript.
- Bản chất: Được biên dịch thành React.createElement() - một Object JS.
- Mục đích: Gom logic xử lý và giao diện vào một "Component".

------------------------------------------------------------
2. QUY TẮC ĐẶT TÊN (NAMING CONVENTIONS)
- Tên File: PascalCase (Ví dụ: UserProfile.jsx).
- Tên Component: PascalCase (Bắt buộc viết hoa chữ cái đầu).
- Biến/Import: PascalCase cho Component, camelCase cho biến thường.
- HOC (Higher-Order Component): camelCase kết hợp PascalCase 
  (Ví dụ: withAuth(WrappedComponent)).

------------------------------------------------------------
3. SO SÁNH HTML VS JSX
- Class: HTML dùng 'class' -> JSX dùng 'className'.
- Sự kiện: HTML dùng 'onclick' -> JSX dùng 'onClick={hàm}'.
- Thẻ đơn: HTML dùng <img> -> JSX bắt buộc dùng <img /> (có dấu /).
- Style: HTML dùng string -> JSX dùng Object {{ color: 'red' }}.
- Biến: JSX dùng dấu ngoặc nhọn { } để nhúng mã JavaScript.

------------------------------------------------------------
4. BA QUY TẮC "VÀNG" CỦA JSX
- Một phần tử gốc: Phải bọc tất cả trong 1 thẻ cha hoặc Fragment <>...</>.
- Đóng mọi thẻ: Kể cả <br />, <input />, <img />.
- Thuộc tính camelCase: Viết strokeWidth thay vì stroke-width.

------------------------------------------------------------
5. LƯU Ý VỀ ĐUÔI FILE (.js vs .jsx)
- Với Vite: Bắt buộc dùng .jsx cho file chứa mã JSX.
- Với VS Code: Đuôi .jsx giúp gợi ý code (Emmet) nhanh hơn.
- Với Logic thuần: Chỉ dùng .js khi file không chứa giao diện.

------------------------------------------------------------
6. VÍ DỤ MÃ NGUỒN MẪU (DÀNH CHO COMPONENT)

import React from 'react';

function UserProfile() {
  const user = { name: "Gemini", isAdmin: true };

  return (
    <>
      <div className="container">
        <h1 style={{ color: 'blue' }}>Xin chào, {user.name}</h1>
        {user.isAdmin && <p>Bạn có quyền Admin</p>}
        <button onClick={() => alert('Thành công!')}>
          Nhấn vào đây
        </button>
      </div>
    </>
  );
}

export default UserProfile;

------------------------------------------------------------

B4: Import và sử dụng Component trong App.jsx.
B5: Chạy lệnh build để biên dịch JSX sang JS thuần cho trình duyệt.
